# 如何开始使用 libGDX？
libGDX 提供了一个[设置工具](/wiki/start/project-generation)，可以自动创建项目并下载所有必需的内容。
{: .notice}

开始时，请先看看我们的 **[设置说明](/wiki/start/setup)** 页面，它会带你一步步完成**使用我们的设置工具创建你的第一个 libGDX 项目**的过程。之后，我们强烈推荐阅读 **[一个简单的游戏](/wiki/start/a-simple-game)** 和 [扩展简单的游戏](/wiki/start/simple-game-extended) 两页。如果你对游戏开发完全是新手、从未开发过游戏，tann 编写的这个（更加简单直观的）[教程](https://colourtann.github.io/HelloLibgdx/)也值得作为替代一看。

从那以后，我们的 [wiki](/wiki/) 就是你最好的伙伴：它为 libGDX 提供的几乎每一个功能都提供了详尽的文档。如果还有其他问题，我们的官方 [Discord 服务器](/community/)是一个不错的起点。

如果你想探索其他（第三方）教程，或者查看一些 demo 和其他开源 libGDX 游戏作为参考，可以从这篇 [wiki 文章](/wiki/start/demos-and-tutorials)开始找起。

# 文档
libGDX 的代码库有两种文档形式：
- 我们的 [Wiki](/wiki/)
- 以及 [Javadoc](https://javadoc.io/doc/com.badlogicgames.gdx)

请注意，我们最近下线了托管在 libgdx.badlogicgames.com 上的 Javadoc。文档**现在可以在 [javadoc.io](https://javadoc.io/doc/com.badlogicgames.gdx) 上找到**。
{: .notice}

# 工具与库
有许多工具和库可以让 libGDX 的开发过程更轻松。一些最常用的工具请参见我们的 **[工具列表](/dev/tools/)**。

我们喜爱的库的精选列表见 **[Awesome-libGDX](https://github.com/rafaskb/awesome-libgdx#readme)**。在我们的 Discord 服务器上，还收藏了大量以 libGDX 为中心、目前正在开发中的库。

# 为 libGDX 做贡献
为 libGDX 做贡献有多种形式：你可以[报告 issue](/dev/issues/)、在我们的 [Discord](/community/) 上帮忙解答、在 [Patreon 页面](/funding/)上赞助，或者[向 GitHub 上的项目提交代码和文档](/dev/contributing/)。更多信息请查看 GitHub 上的 [CONTRIBUTING.md](https://github.com/libgdx/libgdx/blob/master/.github/CONTRIBUTING.md) 文件！
