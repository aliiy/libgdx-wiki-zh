[Skin Composer](https://github.com/raeleus/skin-composer) 是一个方便的工具，可以简化创建 Scene2D 皮肤的过程。其完善的 [wiki](https://github.com/raeleus/skin-composer/wiki) 提供了使用说明。

### 视频系列：

[![](https://i.ytimg.com/vi/78amAV0_e24/hqdefault.jpg?sqp=-oaymwEXCNACELwBSFryq4qpAwkIARUAAIhCGAE=&rs=AOn4CLBV44KmCMrW8Ocu8fOwYV8ZLV61ag)](https://www.youtube.com/watch?v=78amAV0_e24)


### 功能：
* 实时预览所有控件，并提供可配置选项
* 直接在编辑器中指定着色、平铺和自定义创建的 Drawable
* 包含 BitmapFont 编辑器和类似 Shoebox 的图像字体生成器
* 支持 Freetype，并提供从 Json 生成字体的自定义序列化器
* 支持批量处理多个图像的 Nine-Patch 编辑器
* 集成 TenPatch 支持，可实现智能调整大小和动画 UI
* 实现自定义类以扩展 Skin 功能
* 使用 Scene Composer 创建基本的 Scene2D 布局
* 包含 VisUI 模板和示例项目


## Scene Composer
较新版本的 Skin Composer 还包含 **[Scene Composer](https://github.com/raeleus/skin-composer/wiki/Scene-Composer)**，这是一个所见即所得的编辑器，可以导出 JSON 或 Java 文件，直接在游戏中加载。它可以轻松制作 Scene2D 布局原型，并查看 Skin 的实际效果。
